# 🎮 Game Development Using Multiple AI Agents

## About the Project

This project uses three AI agents to create a simple game.

### 1. Game Designer 🎮

Creates the game characters, levels, challenges, and rewards.

### 2. Game Tester 🧪

Checks the game for mistakes, bugs, unclear rules, and difficulty problems.

### 3. Game Editor ✏️

Fixes the problems found by the tester and prepares the final game.

## How It Works

**Game Designer → Game Tester → Game Editor → Final Game**

## Goal

The goal of this project is to show how different AI agents can work together to design, test, and improve a game.

## Technologies Used

* Python
* AI / LLM
* OpenRouter API
* Multi-Agent System
